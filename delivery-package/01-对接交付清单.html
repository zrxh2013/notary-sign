3. 对接协议

3.1 方式①：URL 跳转（最简单）

直接拼接上方 2.1 入口 URL + 参数，PTAHDAO APP 用 Intent.ACTION_VIEW 或 UIApplication.shared.open 跳转。

3.2 方式②：WebView + 加密 postMessage（推荐生产环境）

// 1. 引入 SDK
import PtahDaoNotarySDK from 'https://zrxh2013.github.io/notary-sign/ptahdao-embed-sdk.js';

// 2. 初始化（生产密钥需与我方协商替换）
const sdk = new PtahDaoNotarySDK({
  notaryUrl: 'https://zrxh2013.github.io/notary-sign/',
  sharedKeyB64: 'HqDTT07JMilo7zkQ0SA2Xt8+B0ndEkma+JhHgtjMSXQ=',  // 开发密钥
});

// 3. 挂载 iframe
await sdk.mount(document.getElementById('notary-iframe'));

// 4. 加密调用（AES-256-GCM）
const result = await sdk.declareEntrySecure({
  trustAccount: 'PT-2026-008251',
  settlementNo: 'SET-20260902-007',
  settlementAmount: '125000',
  holder: '李振华',
  signerName: '李振华',
  signerPhone: '13922887766',
  signerIdcard: '440101199208154321',
  paid: true,
  txHash: 'a1b2c3...',  // 64 位十六进制
});
// result = { sessionId, caseNo, declareLink, entered:true, secure:true }

3.3 安全机制

#防护说明
1AES-256-GCM 加密IV 12B + 密文 + 16B GCM tag，防篡改
2共享密钥不上链32B 密钥双方约定，不随消息传输
3postMessage origin 锁定发送时锁定 targetOrigin，接收时白名单校验
4防重放payload 自动注入 ts 时间戳，10 分钟内有效
