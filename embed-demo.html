PTAHDAO 信托声明签署入口配置

模拟从 PTAHDAO 信托管理平台（路径 /declarations） 跳转到本系统的「受益人声明书签署公证」，有两种集成方式： URL 跳转 iframe + API

② 生成 PTAHDAO 跳转外链（URL GET）

③ 编程式声明入口 API（iframe + postMessage）

④ 加密 postMessage 入口（推荐 APP 端使用）AES-256-GCM

安全机制：持有人信息经 AES-256-GCM 加密后通过 postMessage 传输，避免 URL 明文暴露。
防篡改：GCM tag 校验失败自动拒绝；防重放：payload 内置时间戳，10 分钟内有效。
origin 白名单：接收端只接受 PTAHDAO APP 真实 origin 的请求。

参考格式

URL 外链：
https://zrxh2013.github.io/notary-sign/index.html?from=ptahdao&ta=PT001&sn=SET007&sa=125000&holder=李振华&phone=139...&idcard=...&paid=1

iframe API：
NotaryAPI.declareEntry({ trustAccount:'PT001', settlementNo:'SET007', settlementAmount:'125000', holder:'李振华', phone:'...', paid:true })
